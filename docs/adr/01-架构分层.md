# ADR-01 架构分层：判断归智能体，记账归确定性系统

状态：已采纳 ｜ 2026-09-06

## 背景

系统采用智能体架构，传统软件功能作为智能体的工具。需明确哪些能力交给智能体、哪些保持确定性。

## 方案

- a) 全部智能体化——否决：不可复现（同输入不同评级）、不可审计（溯源断裂）、成本失控
- b) 全部传统软件——否决：采集/审查/核实/分析是语义判断，规则无法枚举
- c) 三层划分——**采纳**

## 决定

三层：**判断层**（定向/采集/审查/核实/分析智能体）｜**记账层**（状态机、信用计算、溯源存储、分发检索、调度）｜**工具层**（fetcher、解析、检索等无状态功能，作为智能体工具）。

硬规则：
- 智能体对记账层的写入一律为**提案**（产出 + 依据），经校验落账；**无溯源不落账**
- 状态迁移由记账层校验执行，智能体只能提议
- 信用变更可重放：同一反馈历史 → 重算得到同一信用值
- 评级与置信度：智能体测变量（结构化证据评估），公式出结论（版本化，公式版本记入推理记录）

## 后果

牺牲少量灵活性换取可审计与可调试；LLM 成本由确定性前置过滤控制（精确去重、粗筛先行）；反馈闭环自然产出各智能体的评测与迭代数据。
