# IIH 数据设计

> 概念与关系见[领域模型](doc-02%20-%20领域模型-Domain-Model.md)；术语以[术语表](doc-03%20-%20术语表-Glossary.md)为准。属性随实现演进，相对易变，本文逐步细化评审。

## 1. 实体属性

| 实体 | 核心属性 |
|---|---|
| 媒介 | 名称、描述 |
| 载体 | 名称、处理管线（ASR / OCR / 解析） |
| 信源 | 标识、类型（机构/站点/人物）、画像、信用（A–F） |
| 情报需求 | 提出方、内容规格（主题、关键词、信源偏好、时效要求等）、生效窗口（可空 = 常驻）、状态 |
| 研究课题 | 问题陈述、提示词（自由文本，可空）、状态（进行中/已结题）、登记方、父课题（自引用，可空，decision-15） |
| 情报条目 | 陈述内容、溯源（信源引用+载体+媒介+采集时间+原文快照/链接）、机翻辅助（不入正本，decision-05）、出处信源、事件时间、评级、状态、作废标记（有效性，正交于状态） |
| 分发记录 | 情报条目、命中需求、消费方、渠道、送达时间、反馈时间 |
| 命题 | 陈述、当前状态、置信度、归属研究课题（可空——独立登记）、登记方（decision-15） |
| 推理记录 | 输入值快照（引用条目的评级、子命题的结论与置信度，取判定时点）、判定规则（含公式版本）、判定者（人或智能体）、时间 |
| 反馈 | 类型（六类型，见领域模型 §6）、理由、评价方、时间 |

关系字段（命中需求、命题归属研究课题、命题引用情报条目 / 子命题、研究课题 / 命题催生需求、父子课题、反馈目标、责任信源）不由属性列承载——对应关系见领域模型 §3 实体与关系。

## 2. 公式（v1）

> 均为确定性映射，公式版本记入推理记录，修订不回溯历史；变量由对应智能体测量（decision-01）。数值相对易变，故入本文不入 decision——调整数值不算架构变更。

### 2.1 内容可信度（核实智能体测变量 → 1–6）

变量：N = 独立信源计数（穿透转引链后）；R = 出处信源的信源可靠度档（A–F）。

| 条件（自上而下首个命中） | 内容可信度 |
|---|---|
| 有反证但未证伪 | 5 |
| N ≥ 2 | 1 |
| N = 1 且 R ∈ {A, B} | 2 |
| N = 1 且 R = C | 3 |
| N = 1 且 R ∈ {D, E} | 4 |
| 完成评估但证据不足（含 R = F） | 6 |

表述一致性变量 v1 暂不纳入，v2 再议。

### 2.2 置信度（分析智能体测变量 → 高/中/低）

变量：M = 引用条目数；W = 最弱引用条目的内容可信度（1–6 中数字最大者）。

| 条件（自上而下首个命中） | 置信度 |
|---|---|
| M ≥ 2 且 W ≤ 2 | 高 |
| W ≥ 5 | 低 |
| 其余 | 中 |

> 上表为**叶子命题（求证核实）**公式，证据=情报条目；**合成命题（逻辑合成）**证据=子命题，置信度由子命题组合——v1 待定（判定方式二分见 decision-15）。

### 2.3 信源信用（记账层计算，decision-04）

有效反馈 +1、事实错误 −2；180 天半衰期；累计分分档映射 A–F（分档阈值实现时定）。归因对象见 decision-08。
