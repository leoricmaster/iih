# IIH 数据设计

> 概念与关系见[领域模型](doc-02%20-%20领域模型-Domain-Model.md)；术语以[术语表](doc-03%20-%20术语表-Glossary.md)为准。属性随实现演进，相对易变，本文逐步细化评审。

## 1. 实体属性

| 实体 | 核心属性 |
|---|---|
| 媒介 | 名称、描述 |
| 载体 | 名称、处理管线（ASR / OCR / 解析） |
| 素材 | 载体、媒介、采集时间、原件对象键（`materials/` 内容寻址）、文件名、音频时长、处理状态（doc-02 §4.5）、失败原因、重试计数、外部转写任务号 |
| 派生 | 素材（或父派生）、生产者（工具+模型 / 智能体 / 人工）、产物（文本或对象引用）、音频时长（ASR 计量） |
| 信源 | 标识、类型（公司/政府/组织/媒体/人物/其他）、确认状态（待确认/已确认；拒绝留痕出队，再归因命中重捞入队）、别名集（旧名留档，归因按别名归入）、对应实体（可空）、画像（立场偏差、独立性关联）、信用（A–F） |
| 途径 | 所属信源（唯一归属）、名称、采集入口（网址 / RSS / 账号 / 线下场景）、媒介、载体能力、更新节奏、领域侧重 |
| 实体 | 标识、类型（机构/人物/产品/技术/地域…，随实现演进）、规范名、别名集、归并历史 |
| 实体提及 | 挂载目标（情报条目 / 命题）、实体、原文依据（span / 引文）、抽取提案溯源（来源条目） |
| 情报需求 | 提出方、内容规格（主题、关键词、信源偏好、时效要求等）、采集频率（可空=继承全局间隔）、事件时效边界（可空=不限）、信源绑定（可空=全部已确认信源）、生效窗口（可空=常驻）、上次采集时间戳、状态 |
| 研究课题 | 问题陈述、提示词（自由文本，可空）、状态（进行中/已结题）、登记方、父课题（自引用，可空，decision-06） |
| 情报条目 | 陈述内容、溯源（信源引用+载体+媒介+采集时间+原文快照）、挂载素材 + 所自派生级（附件路径，可空）、原文链接（自动拉取=实际抓取页）、机翻辅助（不入正本）、出处信源、事件时间、评级、状态、作废标记（有效性，正交于状态） |
| 分发记录 | 情报条目、命中需求、消费方、渠道、送达时间、反馈时间 |
| 命题 | 陈述、当前状态、置信度、归属研究课题（可空——独立登记）、登记方（decision-06） |
| 推理记录 | 输入值快照（引用条目的评级、子命题的结论与置信度，取判定时点）、判定规则（含公式版本）、判定者（人或智能体）、时间 |
| 反馈 | 类型（六类型，见领域模型 §6）、理由、评价方、时间 |

关系字段（命中需求、命题归属研究课题、命题引用情报条目 / 子命题、研究课题 / 命题催生需求、父子课题、反馈目标、责任信源、途径归属信源、信源挂实体、实体被提及 / 提及挂载 / 实体归并）不由属性列承载——对应关系见领域模型 §3 实体与关系。

原文快照三轨：人工提交存文本；自动拉取存对象（快照对象键，MinIO 内容寻址 `snapshots/{sha256}.html`，详情页以存档链接回放，CSP sandbox）；附件路径挂素材 + 所自派生级（原件在素材，条目不内嵌）。

## 2. 公式

> 均为确定性映射，公式版本记入推理记录，修订不回溯历史；变量由对应智能体测量（decision-01）。数值相对易变，故入本文不入 decision——调整数值不算架构变更。

### 2.1 内容可信度（核实智能体测变量 → 1–6）

变量：N = 独立信源计数（穿透转引链后）；R = 出处信源的信源可靠度档（A–F）。

| 条件（自上而下首个命中） | 内容可信度 |
|---|---|
| 有反证但未证伪 | 5 |
| N ≥ 2 | 1 |
| N = 1 且 R ∈ {A, B} | 2 |
| N = 1 且 R = C | 3 |
| N = 1 且 R ∈ {D, E} | 4 |
| 完成评估但证据不足（含 R = F） | 6 |

表述一致性（多条情报陈述同一事件的口径一致度）不作为公式变量——同源问题由转引链穿透与独立信源计数把关。

### 2.2 置信度（分析智能体测变量 → 高/中/低）

变量：M = 引用条目数；W = 最弱引用条目的内容可信度（1–6 中数字最大者）。

| 条件（自上而下首个命中） | 置信度 |
|---|---|
| M ≥ 2 且 W ≤ 2 | 高 |
| W ≥ 5 | 低 |
| 其余 | 中 |

> 上表为**叶子命题（求证核实）**公式，证据=情报条目。

**合成命题（逻辑合成）**公式，证据=子命题（decision-06、decision-07）：变量 W = 最弱子命题置信度（高最优）。

| 条件（自上而下首个命中） | 置信度 |
|---|---|
| 任一子命题为低 | 低 |
| 全部子命题为高 | 高 |
| 其余 | 中 |

单一子命题（其余子课题放弃时）自动继承其置信度，无需特判。

### 2.3 信源信用（记账层计算）

有效反馈 +1、事实错误 −2；180 天半衰期，累计分 score(t) = Σ delta·2^(−(t−tᵢ)/180d)；累计分分档映射 A–F。归因对象见 decision-04。

信用档生命周期：种子登记时人工必设初始档（A–F，表单默认 C 中性）——必设以解死锁：未设档 → 核实存疑 → 反馈口不开（仅已核实条目开放）→ 档无从设起。此后由信用通路反馈按累计分重设（公式不变，可重放）。人工可在信源画像页补设/调整（直接生效）；未设档信源的存疑条目在补设后经「重新核实」回流救活（doc-02 §4.1）。素材归因补记的新信源待确认，不设档、不记账；确认入池时人工必设初始档（同种子登记），可修正名与类型——撞既有已确认信源名即并入该信源（条目/转引链/途径随迁，同名途径复用，信用档沿用目标），拒绝即出队（事件表留痕），再次归因命中同名信源重捞入队并提示曾拒。确认改名/并入/画像页改名时旧名留档为别名（全局唯一），此后归因解析按名→别名归入，不再重复产生待确认行。

| 累计分区间 | 分档 |
|---|---|
| ≥ 8 | A |
| [4, 8) | B |
| [0, 4) | C |
| [−4, 0) | D |
| [−8, −4) | E |
| < −8 | F |
