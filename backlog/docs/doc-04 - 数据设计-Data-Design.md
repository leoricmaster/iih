# IIH 数据设计

> 概念与关系见[领域模型](doc-02%20-%20领域模型-Domain-Model.md)；术语以[术语表](doc-03%20-%20术语表-Glossary.md)为准。属性随实现演进，相对易变，本文逐步细化评审。

## 1. 实体属性

| 实体 | 核心属性 |
|---|---|
| 媒介 | 名称、描述 |
| 载体 | 名称、处理管线（ASR / OCR / 解析） |
| 信源 | 标识、类型（机构/站点/人物）、画像、信用（A–F） |
| 情报需求 | 提出方、类型（订阅/任务）、内容规格（主题、关键词、信源偏好、时效要求等）、生效窗口、状态 |
| 情报条目 | 陈述内容、溯源（信源引用+载体+媒介+采集时间+原文快照/链接）、事件时间、评级、状态 |
| 命题 | 陈述、当前状态、置信度 |
| 推理记录 | 判定规则（含公式版本）、判定者（人或智能体）、时间 |
| 反馈 | 类型（六类型，见领域模型 §6）、理由、评价方、时间 |

关系字段（命中需求、关联命题、引用情报条目、反馈目标、责任信源）不由属性列承载——对应关系见领域模型 §3 实体与关系。
