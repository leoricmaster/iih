# IIH 智能体规约

> 判断层五类智能体的判定依据与边界。输入输出见领域模型 §2.1，提案结构见技术架构 §5，术语以术语表为准。prompt 与模型选型属实现，不在本文。

## 1. 总则

五类智能体共性约束：

1. **无状态**：每次调用独立，跨调用状态一律由记账层持有；
2. **提案制**：对系统的全部写入均为提案，经状态机执行器校验落账，无溯源不落账；
3. **变量与结论分离**（decision-01）：凡评级与置信度，智能体只测结构化证据变量，结论由版本化公式计算，公式版本记入推理记录；其余语义判断（相关性、事件同一性、陈述识别）由智能体直接给出；
4. **成本纪律**（decision-01）：LLM 调用前有确定性前置过滤（精确去重、粗筛），过滤掉的素材不进入智能体；
5. **不互通**：智能体间不直接通信，输入由记账层组装，输出为提案。

## 2. 定向智能体

- **判定**：将情报需求翻译为采集任务——依据信源画像选目标信源与媒介，依据内容规格（主题、关键词、信源偏好、时效）定检索参数，依据时效与生效窗口定采集节奏；上下文可含提示词（自由文本），指标清单与信源指引进采集依据，留空则自行发挥（decision-15）；并按提示词将研究课题递归分解为子课题与情报需求（v1 手动 / v2 自动提案）。
- **工具**：信源画像查询、需求与历史采集效果读取。
- **提案**：采集任务。
- **出口**：信源池覆盖不足时按现有信源降级产出，不自行引入新信源——新信源准入走双通道确认制（decision-09）。

## 3. 采集智能体

- **形态**：按载体配备（网页/录音/文字/图片/文档），处理管线（ASR/OCR/解析）为其工具。
- **判定**：从原始素材识别潜在情报陈述，组装线索（陈述内容 + 溯源引用）。
- **前置过滤**：素材先过确定性去重（URL/内容指纹比对已采条目），命中不进智能体，仅在既有条目转引链追加该信源引用（decision-10）。
- **发现**：执行采集任务时可按配置比例做池外自由探索，上报新信源发现提案，经用户确认入信源库（decision-09）。
- **工具**：fetcher、解析管线、素材存储读取。
- **提案**：情报条目新建（线索态，溯源五要素齐备）；新信源发现。
- **人工录入**：人工提交是采集模式之一（由媒介派生），素材走同一处理管线、同一线索产出，不经定向任务化，直接进入审查。

## 4. 审查智能体

- **判定**：三维度把关——相关性（对声明的情报需求）、事件同一性（合并键 = 相同核心陈述 + 事件时间窗，decision-02）、有效性初筛；事件同一性命中按新信源分流——带来链上没有的信源则放行核实合并印证，同源纯重复才否决为重复（decision-10）。
- **去重分工**：指纹级去重在采集前置过滤（确定性）；语义级事件同一性判定在审查（判断层）。
- **工具**：线索与既有条目读取、需求读取。
- **提案**：审查结论——通过为候选，或否决为噪音（附理由：不相关/重复/无效）。

## 5. 核实智能体

- **流程**：合并印证（事件同一性命中则并入既有条目，转引链保留全量信源，decision-02）→ 穿透转引链至一次信源 → 统计独立信源 → 评定内容可信度。
- **变量与结论**：测结构化证据变量（独立信源计数、出处信源可靠度；表述一致性留待 v2），公式出内容可信度 1–6（数据设计 §2.1）；信源可靠度维（A–F）不测，取信源画像当前值，组装为二维评级。
- **工具**：外部信源检索（佐证）、转引链与画像读取。
- **提案**：评级提案（A1–F6）；判定不实 → 否决，反证未证伪按公式降级（数据设计 §2.1）；无法完成 → 存疑（挂起，可设复核期，decision-03）。
- **评级重评**（decision-07）：由本智能体重新评定，触发器由调度持有。

## 6. 分析智能体

- **判定**：基于已核实条目 / 子命题与答案命题，做证实/证伪/存疑判定；叶子命题从情报判定，合成命题按框架取子命题合成。
- **变量与结论**：测证据组合的结构化变量（v1：引用条目数、最弱条目可信度；独立信源计数与时效留待 v2），公式出置信度 高/中/低（数据设计 §2.2）。
- **工具**：已核实条目检索、命题与推理记录读取。
- **提案**：命题判定（结论 + 置信度 + 推理记录：引用条目 / 子命题 + 判定规则含公式版本 + 判定者 + 时间）。
- **重估**：结论被挑战（新证据/级联重估）时重新判定，历史推理记录不覆盖。
- **测算类课题**：上下文可含提示词（测算框架）；按提示词分解为子课题（各测算法）+ 叶子情报需求，构造性测算（如市场空间测算）v1 分解与构造由人工完成、判定者记人，系统职责为参数采集与证据记账，置信度仍由公式从账本变量计算（decision-15）。

## 7. 命题与判定

命题有独立状态与生命周期（decision-15）：可独立登记（世界递来的断言）、可归属研究课题（答案命题 / 子结论）、可被多个问题引用。答案命题生于研究课题内——登记时转写（可选：估算类可不转写，最终答案作答即判定）、智能体提案（提案制现成，列 v2 再议）。判定归分析智能体（构造性测算 v1 人工，判定者记人，decision-15），命题状态机见领域模型 §4.4。

两类催生并存（decision-15）：研究课题催生情报需求盯输入（v1 消费方按提示词指标清单落成，一次性之后无人值守；定向智能体自动提案列 v2）；命题催生情报需求盯证据（求证导向，同 v1 手动 / v2 自动提案）。研究课题可递归分解为子课题（问题树），非叶子课题的命题由分析智能体取子命题按框架合成。
