# IIH 智能体规约

> 判断层五类智能体的契约：输入、职责、输出、工具。提案结构见技术架构 §5，术语以术语表为准。prompt 与模型选型属实现，不在本文。
> 每类智能体按「输入 / 职责 / 输出 / 工具」四栏组织，四栏固定同序；专有约束并入相关栏。

## 1. 总则

五类智能体共性约束：

1. **无状态**：每次调用独立，跨调用状态一律由记账层持有；
2. **提案制**：对系统的全部写入均为提案，经状态机执行器校验落账，无溯源不落账；
3. **变量与结论分离**（decision-01）：凡评级与置信度，智能体只测结构化证据变量，结论由版本化公式计算，公式版本记入推理记录；其余语义判断（如相关性、事件同一性、陈述抽取）由智能体直接给出；
4. **成本纪律**（decision-01）：LLM 调用前有确定性前置过滤（精确去重、粗筛），过滤掉的素材不进入智能体；
5. **不互通**：智能体间不直接通信，输入由记账层组装，输出为提案。

五类智能体即流水线上的全部判断点；分发匹配、反馈路由、信用计算等记账层机制为确定性，不设智能体；无状态工具（抓取/解析/检索/存储读写）属工具层，作为智能体工具被调用。

## 2. 定向智能体

- **输入**：情报需求；研究课题（可含提示词：指标清单、测算框架、信源指引等自由文本）。
- **职责**：将情报需求翻译为采集任务——依据信源画像（主体的立场、独立性、信用）与途径画像（出口的节奏、领域侧重）选目标途径（decision-17），依据内容规格（主题、关键词、信源偏好、时效）定检索参数，依据时效与生效窗口定采集节奏；按提示词将研究课题递归分解为子课题与情报需求，留空则自行发挥（decision-15）。信源池覆盖不足时按现有信源降级产出，不自行引入新信源——新信源准入走双通道确认制（decision-09）。
- **输出**：采集任务提案（目标途径、检索参数、采集节奏，decision-17）；研究课题分解产物提案（子课题、情报需求）。
- **工具**：信源与途径画像查询、需求与历史采集效果读取。

## 3. 采集智能体

- **输入**：采集任务；原始素材（按载体经处理管线：ASR/OCR/解析）；人工提交为另一路径，不经定向任务化，直接进入审查。
- **职责**：从原始素材识别潜在情报陈述，组装线索（陈述内容 + 溯源引用——非互联网途径不经登记，由此归因补记），并自陈述抽取实体提及（世界对象锚定，decision-16）；执行采集任务时可按配置比例做池外自由探索。
- **输出**：情报条目新建提案（线索态，溯源五要素齐备，含实体提及——既有实体引用或新实体建立）；新信源发现提案（经用户确认入信源库，decision-09；发现来源含池外自由探索与人工提交素材的溯源归因）。
- **工具**：fetcher、解析管线（按载体配备：网页/录音/文字/图片/文档）、素材存储读取；**前置过滤**——确定性去重（URL/内容指纹比对已采条目），命中不进智能体，仅在既有条目转引链追加该信源引用（decision-10）。

## 4. 审查智能体

- **输入**：线索。
- **职责**：四维度把关——相关性（对声明的情报需求；图连通度为参考变量，断连孤岛另作新话题提示）、事件同一性（合并键 = 相同核心陈述 + 事件时间窗，decision-02）、实体同一性（归一：提及与既有实体的同一性判定——新实体随提及建立，归并既有实体走提案 + 消费方确认，decision-16）、有效性初筛；事件同一性命中按新信源分流——带来链上没有的信源则放行核实合并印证，同源纯重复才否决为重复（decision-10）。
- **输出**：审查结论提案——通过为候选，或否决为噪音（附理由：不相关/重复/无效）；实体归并提案（decision-16）。
- **工具**：线索与既有条目读取、需求读取、实体与提及读取。去重分工：指纹级去重在采集前置过滤（确定性），语义级事件同一性判定在审查（判断层）。

## 5. 核实智能体

- **输入**：候选条目；可检索外部信源佐证。
- **职责**：合并印证（事件同一性命中并入既有条目，转引链保留全量信源，decision-02）→ 穿透转引链至一次信源 → 统计独立信源 → 评定内容可信度；评级重评由本智能体承担（触发器归调度，decision-07）。**变量与结论分离（decision-01）**：测结构化证据变量（独立信源计数、出处信源可靠度），公式出可信度 1–6（数据设计 §2.1）；信源可靠度维（A–F）不测、取信源画像当前值，组装为二维评级。
- **输出**：评级提案（A1–F6）；判定不实 → 否决，反证未证伪按公式定可信度 5（数据设计 §2.1）；无法完成 → 存疑（挂起，可设复核期，decision-03）。
- **工具**：外部信源检索（佐证，实体 + 事件锚定）、转引链与画像读取。

## 6. 分析智能体

- **输入**：已核实条目（叶子命题证据）、子命题（合成证据）。
- **职责**：给命题下判定——证实、证伪或存疑，附置信度与推理记录。判法二分（decision-15）：
  - 叶子命题（求证核实）：从已核实情报条目判定，证据=情报条目。
  - 合成命题（逻辑合成）：取子命题的判定结果按合成框架合成，证据=子命题；合成框架由提示词给定（如测算框架）或取内置逻辑规则。
  结论被新证据或级联重估挑战时进入重估中、重新判定，历史推理记录不覆盖。**变量与结论分离（decision-01）**：叶子命题测引用条目数、最弱条目可信度，公式出置信度 高/中/低；合成命题测各子命题置信度，按最弱链公式出置信度（数据设计 §2.2，decision-18）。
- **输出**：命题判定提案（结论 + 置信度 + 推理记录：引用条目 / 子命题 + 判定规则含公式版本 + 判定者 + 时间）。
- **工具**：已核实条目检索、命题与推理记录读取。

## 7. 命题与判定

判定对象为命题（decision-15）：三种来历——独立登记（世界递来的断言）、归属研究课题（答案命题 / 子结论）、被多个问题引用；命题独立于研究课题存续，状态机见领域模型 §4.4。判定归分析智能体。

两类催生情报需求并存（decision-15）：研究课题催生盯输入、命题催生盯证据。研究课题递归分解为子课题（问题树），非叶子课题命题由分析智能体取子命题按框架合成（§6）。
