## Description

登记种子信源 → 两条素材入口并行产出线索（人工录入素材、互联网信源自动拉取）→ 审查过滤 → 核实评级 → 收件箱浏览 → 类型化反馈 → 信源信用更新，端到端跑通（对应 Feature IIH-01 单信源监控闭环）。验证判断/记账分层骨架：定向、采集、审查、核实四个智能体到场（最简实现），记账层以状态机执行器为唯一写账入口，信用计算器、反馈路由、溯源存储随故事到场。调度节奏、池外自由探索、多途径编排、主动推送另立后续里程碑；分发匹配、事件同一性、实体归一、级联重估传播深度后续加厚。实现顺序按故事依赖链渐进切片（录入奠基 → 信源登记 → 自动拉取 → 审查 → 核实 → 收件箱 → 反馈 → 信用）。
